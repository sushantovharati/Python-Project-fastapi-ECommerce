# Python-Project-fastapi-ECommerce
A simple Ecommerce API built using FastAPI with file-based storage (no database). It supports two roles: Admin and Customer, and provides full CRUD operations for both.

This is a simple E-Commerce API project built using **FastAPI**.  
The project demonstrates basic API functionality with two roles: **Admin** and **Customer**.  
A separate Python client is used to interact with the API.

## Requirements
Make sure you have **Python 3.8+** installed.

### Required Libraries
Necessary libraries to install: fastapi, uvicorn and requests.

### To Run this project:
To Start API: uvicorn server:app  
To RUN Client: python client.py
